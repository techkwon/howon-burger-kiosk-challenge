# 🍔 호원버거 키오스크 챌린지

키오스크 앞에서 겪는 어려움을 직접 체험해 보는 **중학교 교양 수업용 웹 게임**입니다.
손님 쪽지대로 주문하면 클리어 — 단계가 올라갈수록 실제 키오스크의 장벽이 하나씩 붙습니다.

**플레이: https://ict-kiosk-challenge.netlify.app**

> 「정보 통신 기술에서 소외받는 사람들 이해」 차시에 쓰려고 만들었습니다.
> 학생이 **지팡이를 짚은 할아버지가 되어** 주문합니다. 마지막에 묻습니다 —
> *"주문한 사람은 똑같았어요. 달라진 건 무엇이었나요?"*

---

## 한 파일입니다

`index.html` 하나가 전부예요. **외부 글꼴 · 라이브러리 · 이미지 · 서버 · 저장 없음.**
3D도 CSS `perspective` / `translateZ` 와 CSS로 그린 캐릭터로만 만들었습니다(구형 크롬북 기준).
받아서 브라우저로 열면 바로 됩니다.

## 이렇게 진행돼요

1. **타이틀** — 가게 앞 거리를 사람들이 지나다닙니다. `▶ 시작하기`
2. **할아버지가 키오스크 앞까지 걸어와 섭니다.** 여기서부터 플레이어가 그 할아버지
3. **10단계** — 쪽지대로 주문. 쪽지와 다르면 결제까지 갈 수 없습니다
4. **고쳐서 다시** — 글씨 크게 · 한국어 · 광고 끄기 · 흔들림 없애기 · 시간 제한 없애기 · 소리로 읽기를 켜고 같은 단계를 다시

## 10단계

| 단계 | 붙는 장벽 | 시간 |
|---|---|---|
| 1 따라 하는 연습 | — (설명대로만 누를 수 있음) | 없음 |
| 2 여러 개 담기 | 수량 바꾸기 | 35초 |
| 3 세트 고르기 | 사이드 · 음료 · 크기를 또 고름 | 40초 |
| 4 여러 메뉴판 | 칸을 오가야 함 | 45초 |
| 5 광고와 팝업 | 2초간 안 닫히는 광고 · 세트 권유 | 50초 |
| 6 작은 글씨 | 글씨 작음 · 그림 없음 · 이름 비슷 · 순서 섞임 | 50초 |
| 7 모르는 말 | 화면 전체 영어 | 50초 |
| 8 재촉하는 줄 | 재촉 문구 · 8초 멈추면 처음으로 | 40초 |
| 9 떨리는 손, 흐린 눈 | 화면 흔들림 · 흐림 | 55초 |
| 10 점심시간 러시 | 위 장벽이 한꺼번에 | 60초 |

**쪽지는 할 때마다 새로 뽑힙니다** — 메뉴 · 옵션 · 매장/포장 · 포인트 적립(전화번호) ·
결제 방법(카드 / 모바일 쿠폰+번호 / 간편결제)까지. 1단계 안내 문구도 뽑힌 쪽지에 맞춰 바뀝니다.

## 🔥 콤보와 ⭐ 점수

안 틀리고 쭉 맞게 누르면 콤보. **5콤보마다 +3초.**
점수 = `콤보 점수(10 × 현재 콤보)` + `클리어 500` + `남은 초 × 40`.
막힘 0회 + 시간 40% 이상 남기면 ⭐3. 같은 단계를 다시 하면 더 높은 점수만 남습니다.

## 주소 뒤에 붙이는 것

| | |
|---|---|
| `?stage=7` | 그 단계부터 바로 시작 (1~10) |
| `?fixed=1` | 쪽지를 고정 (시연 · 자동 시험용) |

## 수업에서 쓸 때

- 점수는 **게임 점수**입니다. 평가가 아니라고 먼저 말해 주세요. 반 전체로 비교하지 않습니다
- 9단계(흔들림 · 흐림)는 어지러움을 느끼는 학생이 있으면 바로 넘어가도 된다고 미리 안내해 주세요
- 「소리로 읽기」는 이어폰이 없으면 교실이 시끄러워집니다
- 결과는 각자 브라우저에만 남습니다. 서버 저장 · 전송이 없습니다

가져다 고쳐 쓰셔도 됩니다. 메뉴 · 단계 · 장벽은 `index.html` 안의 `MENU`, `STAGES` 만 고치면 됩니다.
